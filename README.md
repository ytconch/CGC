# 您在說什麼：本地內網遊戲控制工具

## 啟動

```powershell
npm.cmd start
```

電腦打開伺服器顯示的本機網址後，畫面會先停在 QR Code。手機與電腦連到同一個 Wi-Fi，再掃描 QR Code 進入控制頁；手機進入後，電腦會自動切換到比賽畫面。

## 現場注意

- 第一次啟動時，Windows 防火牆可能會詢問是否允許 Node.js 存取私人網路，請允許。
- 題庫在電腦端按「題庫建置」貼上，一行一題；按「建置三回合」後會隨機平均分配到第 1、2、3 回合，並保存在本機 `data/questions.json`。
- 手機端可以切換第 1、2、3 回合；每回合都有自己的題目進度、A/B 分數與計時。
- 如果切換回合時目前回合正在計時，系統會先把該回合暫停，避免不同回合的計時同時跑。
- 手機控制頁不需要密碼，同網路能打開網址的人都可以控制。
